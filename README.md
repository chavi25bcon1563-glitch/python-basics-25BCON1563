# python-basics-25BCON1563
## Session 4 Python Programs

## WHAT

This repository contains six fundamental Python programs:

- **Star Pattern.py**: Checks if a given number is an Armstrong number.
- **factorial.py**: Calculates the factorial of a number using a loop.
- **fibonacci.py**: Generates a Fibonacci sequence up to a specified number.
- **prime.py**: Determines whether a given number is prime.
- **even or odd.py**: Checks if a number is a pronic number (product of two consecutive integers).
- **struct.py**: Stores and prints student details using a Python dictionary.

## RUN

You can execute each script directly from your terminal using Python:

- `python Star pattern.py`
- `python factorial.py`
- `python fibonacci.py`
- `python prime.py`
- `python even or odd.py`
- `python struct.py`

## NEEDS

- Requires Python 3.x installed on your system.
- `pronic.py` uses the built-in `math` module.
- No external dependencies are required.
